# Temperature Converter

## Purpose
This project is a simple Python program that converts a temperature from Celsius to Fahrenheit. It is designed to practise Git and GitHub.

## How to Run
1. Make sure Python 3 is installed.
2. Open the project folder in VS Code.
3. Open the terminal and run:

   `python3 temperature_converter.py`

4. Enter a temperature in Celsius when prompted.

## Example Input/Output

**Input:**
```text
Temperature in Celsius: 25
```

**Output:**
```text
Fahrenheit: 77.00
```
